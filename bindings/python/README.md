## 🔧 Installation

Rekordbox-IO is available on PyPI:

```bash
pip install rbox
```

The Python bindings can also be built manually via [pyo3] and [maturin]:
```bash
maturin develop
```

[pyo3]: https://github.com/PyO3/pyo3
[maturin]: https://github.com/PyO3/maturin
