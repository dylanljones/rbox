# codegen

Internal Rust source inspection utilities for rbox's code generation tools.
This crate is unpublished.

> [!NOTE]
> This crate is part of [rbox](https://crates.io/crates/rbox).

Use `parse_rust_file` or `parse_rust_source` to inspect modules, types, and
functions as structured models, and `walk_rust_files` to discover source files.
