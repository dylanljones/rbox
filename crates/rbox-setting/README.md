# rbox-setting

Read, edit, and write Rekordbox `*SETTING.DAT` files containing player, mixer,
and device preferences.

> [!NOTE]
> This crate is part of [rbox](https://crates.io/crates/rbox), available through `rbox::settings`.

Supports `MYSETTING.DAT`, `MYSETTING2.DAT`, `DJMMYSETTING.DAT`, and
`DEVSETTING.DAT`, with typed setting values and errors.
